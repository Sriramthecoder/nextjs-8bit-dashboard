# 🕹️ 8bit Dashboard

A retro 8-bit styled dashboard built with **Next.js**, **shadcn/ui**, and the nostalgic charm of **8bitcn**. Designed for developers who love a pixel-perfect blend of modern stack and vintage vibes.

---

## ✨ Features

- 🎮 Retro 8-bit themed UI with `8bitcn`
- ⚡ Fast and scalable frontend using `Next.js`
- 💅 Beautiful, customizable components via `shadcn/ui`
- 🌗 Dark mode support (optional)
- 📱 Responsive layout for all devices
- 🧱 Modular component structure for easy customization

---

## 🛠️ Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **UI Components:** [shadcn/ui](https://ui.shadcn.com/)
- **Theme Styling:** [8bitcn](https://www.npmjs.com/package/8bitcn)
